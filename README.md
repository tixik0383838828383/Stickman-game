# Stickman Paper Parkour

2D-платформер «оживший рисунок». HTML5 Canvas + Web Audio, без библиотек, работает офлайн.

## Запуск
- **ПК:** открой `index.html` (или `dist/stickman_paper_parkour.html`) двойным кликом — сервер не нужен (спрайт-лист встроен в `assets/sheet_data.js`).
- **Телефон:** скопируй `dist/stickman_paper_parkour.html` на телефон и открой в браузере; либо упакуй в APK приложением «HTML to APK». Сенсорные кнопки включаются автоматически.
- Хеш `#all` в адресе открывает все уровни (для отладки).

## Управление
A/D или стрелки — бег; Пробел/W/↑ — прыжок (удержание = выше); S/↓ — присесть, на бегу — скольжение; R — с чекпоинта; Esc — пауза.
Стена: прижмись и жми прыжок (wall slide / wall jump). Верёвка: прыжок — вверх, ↓ — вниз, направление + прыжок — спрыгнуть.

## Как заменить спрайт-лист
Положи новый PNG в `assets/stickman_sheet.png`, запусти `python3 tools/prep_sprites.py` (разметка кадров) и `python3 tools/build.py`. Затем в игре: меню → **Sprite Inspector** → выбери кадры, задай имя (`run`, `jump`…), FPS → «Создать» → «Применить и сохранить». Экспорт/импорт JSON — там же. Непрозрачный тёмный фон убирается цветовым ключом автоматически.

## Как добавить уровень
1. В игре: **Редактор уровней** → расставь объекты → «Проверка» → «Бот» (докажет проходимость) → «Тест» → «Сохранить». Уровень попадёт в «Мои уровни»; JSON — «Экспорт».
2. Или в `js/levels.js` через билдер `LB()`: `b.plat(x,y,w,h,'solid')`, `b.spike…`, `b.coin(x,y)`, `b.cp(x,y)`, `b.fin(x,y)`; добавь уровень в массив. Проверка: `node tests/bot.js N`.
